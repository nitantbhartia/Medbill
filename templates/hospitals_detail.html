How we grade this hospital

BillKarma calculates billing grades by comparing each hospital's gross charges to the 2026 Medicare Outpatient Prospective Payment System (OPPS) rate for the same CPT codes. We download and parse each hospital's CMS-mandated price transparency file, match procedure codes to Medicare benchmarks, calculate a markup ratio for each matched procedure, and average those ratios across all matched procedures to produce the hospital's overall markup.

Grade thresholds: A = 2.0x Medicare or less · B = 2.1x–3.0x · C = 3.1x–5.0x · D = 5.1x–8.0x · F = More than 8.0x Medicare

Data sources: CMS Hospital Price Transparency files (updated annually), CMS OPPS 2026 Final Rule, CMS Hospital Compare (star ratings). Grades are recalculated when hospitals post updated price files. Last file parse date is shown above.
