Hospital billing grades

Each hospital with a usable price file gets a billing grade from A to F. The grade shows how far the hospital’s list prices run above what Medicare pays for the same services.

Download the grades (CSV)

How the grade is calculated

Every U.S. hospital must publish a machine-readable price file listing what it charges for procedures. For each hospital we compare the gross charge in that file (the list price before discounts or insurance) with what Medicare pays hospitals for the same billing code under the outpatient Prospective Payment System (OPPS). Codes Medicare doesn’t pay that way, such as lab tests and inpatient surgery, are left out. We average the ratio across the remaining procedures after removing extreme outliers. A hospital needs at least {{ config.RANKING_MIN_PROCEDURES }} comparable procedures to be graded.

Grades are based on gross charges, not on what a patient pays. Insurers negotiate discounts from gross charges, but deductibles and coinsurance are often calculated from them. A hospital with no grade usually has a missing, incomplete or unreadable price file.

Grade scale

GradeAverage markup vs. Medicare
ABelow 2.0x
B2.0x to below 3.0x
C3.0x to below 5.0x
D5.0x to below 8.0x
F8.0x or more

A billing grade is not a measure of care quality. Use the CMS star rating alongside it. See the full method and grading guide.

Fields in the CSV

FieldMeaning
facility_idIdentifier BillKarma uses for the hospital
nameHospital name, as on its BillKarma profile page
city, stateLocation; state is the two-letter code
ownershipOwnership type as recorded in the source hospital data
billing_gradeA to F, from the grade scale above
avg_markup_vs_medicareAverage of gross charge divided by the Medicare rate, across the procedures compared. 1.0 means the same as Medicare.
procedures_comparedNumber of procedure codes in that average
profile_urlThe hospital’s BillKarma profile page

Hospital prices come from each hospital’s price transparency file. Medicare rates come from CMS.

Embed a grade

Each graded hospital’s profile page has an “Embed this grade” box with a badge image and a link back to the profile. The badge image is at /badge/<facility_id>.svg.
