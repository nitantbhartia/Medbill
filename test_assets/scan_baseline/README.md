# Scan Baseline Pack

This folder provides a repeatable baseline dataset for validating scan/extraction quality.

## What is included

- `synthetic/`:
  - 18 deterministic synthetic fixtures across 3 layouts:
    - statement-style medical bills
    - EOB-style summaries
    - portal-style outstanding balance screens
  - Generated by `scripts/generate_synthetic_baselines.py`.
- `synthetic_ground_truth.jsonl`:
  - Ground truth for each synthetic file (`total_charged`, `total_patient_owes`, `line_items`).
- `public/`:
  - Publicly accessible real-world layout samples.
- `public_manifest.csv`:
  - Source attribution + notes for public files.

## Why this structure

- Public links are valuable for realism but can be unstable over time.
- Synthetic fixtures are deterministic and stable for CI/regression.
- Combined pack gives both reliability and layout diversity.

## Regenerate synthetic fixtures

```bash
python3 test_assets/scan_baseline/scripts/generate_synthetic_baselines.py
```

## Refresh public samples

```bash
test_assets/scan_baseline/scripts/fetch_public_samples.sh
```

## Recommended usage

1. Run scan extraction over all files in `synthetic/` and compare against `synthetic_ground_truth.jsonl`.
2. Track key metrics per run:
   - line item recall
   - CPT detection accuracy
   - `total_patient_owes` extraction/capping correctness
3. Smoke-test parser robustness against files in `public/` for real-world layout drift.

## Notes

- Public files are used as test fixtures only; keep source attributions in `public_manifest.csv`.
- Synthetic files contain no PHI.
